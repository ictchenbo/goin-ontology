# 决策方案可选性修复 v2

[页面依据] “决策与审批”的方案下拉框仍展示被禁用的不可行方案，用户会在选择时看到无法操作的选项。

## 设计

- [设计方案] “方案与评估”继续展示全部备选方案及评分原因，保留评估与审计信息。
- [设计方案] “决策与审批”的下拉框仅展示本次评分判为可行、且方案状态允许选择的方案；不可行和未评分方案不进入选项列表。
- [设计方案] 决策区继续显示不可行方案及硬约束原因；没有可行方案时提示返回“方案与评估”处理并重新评分。
- [设计方案] 记录决策与提交审批继续执行现有前后端可行性及时效校验。

## 验收

- [验收目标] 当前案例的“申请法定措施”仍在评估结果和原因中可见，但不出现在“选定方案”下拉框。
- [验收目标] 可行方案仍可选择、记录决策并提交审批。
- [验收目标] 没有可行方案或评分失效时，不会出现可提交的错误选择。
