# 本体模型中的目标意图建模

更新日期：2026-10-12

## 结论

[建议设计] 将“目标意图”定义为**有责任主体、作用对象、期望状态、期限和验收方法的声明**。它回答“希望产生什么结果及为何”，不预先指定必须执行哪个 Action。规则负责计算和判断，备选方案描述可能的手段，Action 执行被授权的状态改变，Outcome 用实际结果验证目标是否达成。

[Palantir 文档依据] Palantir Ontology 提供对象、关系、Action 和函数等建模能力，Action 表达对对象及其关系的受控修改，Scenario 用于评估拟议变化的影响。下文的 `GoalIntent` 是针对本项目提出的业务对象设计，并非引用 Palantir 文档中的同名基础概念。参见 [Ontology 概览](https://www.palantir.com/docs/foundry/ontology/overview)、[Action types](https://www.palantir.com/docs/foundry/action-types/overview)和 [Scenarios](https://www.palantir.com/docs/foundry/vertex/scenarios-overview)。

## 建议的数据语义

[建议设计] 对一次具体目标，至少记录下列信息；“模板默认值”和“案例实际值”应区分，并保留版本或快照。

| 字段组 | 含义 |
| --- | --- |
| [建议设计] 身份与责任 | 意图 ID、表述、提出人、责任人、授权依据、状态、版本。 |
| [建议设计] 作用范围 | 所针对的对象实例或对象集合，以及相关对象的角色。 |
| [建议设计] 期望状态 | 可检验的指标或谓词、比较方向、目标值、单位和期限；可包含多个必要条件。 |
| [建议设计] 边界与偏好 | 不能违反的硬约束、可权衡的软目标及其优先级；权重用于方案比较，不能替代验收条件。 |
| [建议设计] 判定依据 | 基线事实、测量来源、证据新鲜度、判定时间和规则／模型版本。事实不足时保留“未知”，不要判为已达成。 |

[建议设计] 关系可以表达为：`GoalIntent → targets → 业务对象`；`GoalIntent → pursued_by → DecisionCase`；`DecisionCase → considers → Alternative`；`Alternative → proposes → Action`；`ActionRun → produces → 实际对象变化`；`Outcome → evaluates → GoalIntent`。这是建议的语义关系，当前数据库尚未完整实现这些链接。

[建议设计] **一次性目标**可先作为 `decision_case` 的结构化意图快照保存，由 `decision_type` 提供默认目标和评估策略；**跨多个案例持续存在的目标**再提升为本体中的 `GoalIntent` 对象类型，通过关系连接目标对象、多个案例和多次结果。是否提升取决于目标是否需要独立身份、生命周期、负责人和跨案例追踪，而非名称是否含“目标”。

## 示例

[示例假设] 对某个延迟的订单，“在约定交付日前完成交付，且额外成本不超过批准预算”是目标意图；“加急运输”和“跨仓调拨”是备选方案；两者分别调用相应 Action 才可能改变业务状态。方案得分较高，只说明它在给定预测和权重下更可取；仍须依据交付和成本的实际记录判断目标是否达成。

## 建议的处理顺序

1. [建议设计] **声明目标**：确认提出人、目标对象、期望状态、期限、约束与证据要求；自然语言输入转为结构化字段后由责任人确认。
2. [建议设计] **冻结基线**：在案例中保存对象修订、事实来源和目标版本，明确当前状态与目标状态的差距。
3. [建议设计] **生成并比较手段**：先检查硬约束，再用准则和推演比较可行的备选方案；保留预测的不确定性。
4. [建议设计] **授权并执行**：选择方案后，仍由 Action 检查权限、前置条件和对象当前状态。
5. [建议设计] **验收目标**：用 Outcome 的实际指标逐项判断“达成／未达成／证据不足”，记录偏差；未达成时可开启下一轮决策。

## 增补边界

- [待考虑] 是否需要跨案例目标、父子目标、目标冲突和优先级协商。若没有对应业务场景，先保持单案例目标的简洁模型。
- [待考虑] 目标条件应支持哪些可计算表达式，哪些必须由人核验；对证据缺失、测量延迟和目标变更如何留痕。
- [待考虑] 若正式增加 `GoalIntent` 对象类型或新关系，应同步更新 `frontend/public/ontology-concepts.svg` 并验证管理页入口。
