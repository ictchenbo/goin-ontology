# Orient 关联对象与证据表格设计 v1

[需求依据] 案例详情页的“态势构建”区域当前以标签直接显示对象 ID，无法在此处核对对象名称及证据。

## 展示规则

[代码依据] 页面读取案例当前的 Orient 快照。表格每行展示一个快照对象，列为对象、类型、角色和证据。对象标题链接到对象详情，ID 作为辅助信息；根对象标为“触发对象”，其余标为“关联对象”。

[代码依据] 证据列展示快照中可见证据的主张、来源、立场和观测时间；没有可见证据时显示“暂无证据”。无快照时显示引导文案，不使用实时对象或证据冒充快照内容。

[代码依据] 继续使用快照接口的权限裁剪结果，不额外读取当前证据，以保持展示内容与 Orient 时的冻结事实一致。

## 验证标准

[验收目标] 执行 Orient 后，对象标题、类型、角色和对应证据可在表格中核对；无证据和无快照状态清楚；点击对象标题可进入对象详情；前端构建通过。
