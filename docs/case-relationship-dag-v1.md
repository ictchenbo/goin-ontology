# 案例快照对象关系 DAG 展示设计 v1

[需求依据] 案例详情页“对象之间的关系”目前是起点、关系、终点表格；用户要求改为 DAG 图，以便直接看到对象的连接方向与分支汇合。

## 数据与布局

[代码依据] 图只读取当前 Orient 快照的 `objects` 和 `links`。对象以可读标题、类型及触发对象标记作为节点；每条关系以名称作为中间节点，箭头按快照的 `from → 关系 → to` 绘制，不推断因果或规则命中。

[设计目标] 对快照关系做拓扑分层，同一对象只绘制一次，多个关系可以汇入或发出同一节点。按列从左到右排列，画布在窄屏横向滚动。节点可打开对象详情；被裁剪或脱敏的对象仅显示“无权查看”，不显示其标题、类型和 ID。无关系时沿用空状态提示。

[设计目标] 若快照中存在环，提示无法按 DAG 排列，并停止绘图，避免把环误显示成有向无环图。图像使用当前主题颜色，并提供可供辅助技术读取的关系文字列表。

## 验证标准

[验收目标] 公共安全演示快照中，两个事件分别指向其来源，风险指标指向依据事件，个案指向所含事件；每个对象只出现一次，关系名称和箭头清楚可读。前端构建通过，窄屏可查看完整图，空状态及环状态有明确提示。
