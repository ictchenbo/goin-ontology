# Orient 事实、关系与规则判断说明 v1

[需求依据] 案例详情目前只列相关对象与证据，无法回答观察到了什么、对象如何关联、哪些规则命中以及异常结论从何而来；演示观察事件的标题仅有编号。

## 数据与界面

[代码依据] Orient 快照继续作为事实来源。页面先展示触发对象的时间、地点、描述和核实状态，再展示快照中的关系边（起点、关系名称、终点）与对象证据表。关系只表示模型中实际存在的连接，不由页面推断因果。

[设计目标] 构建新快照时，对适用对象类型的已发布触发规则求值，冻结规则名、版本、表达式、输入字段、命中结果或错误。页面把命中显示为“规则提示”，并展示规则说明；命中不等同于异常行为已经核实。旧快照没有冻结结果时明确提示重新执行 Orient，不补写历史结果。

[设计目标] 对快照中的 RiskIndicator，若没有可核查的生成规则运行记录，页面明确显示“指标来源未记录”，避免把预置指标包装为自动识别结果。反证与冲突按快照记录展示。

[设计目标] 公共安全演示事件的对象标题改为“相对具体的事件类型 + 日期 + 编号”。原有 `EVT-...` 保留为业务编号；仅精确匹配演示对象的旧标题做展示名迁移，历史快照事实不改写。旧快照页面可用其冻结描述和日期生成明确的显示名。

## 验证标准

[验收目标] 新快照能回放对象关系、观察事实、触发规则的输入与结果；旧快照会注明规则判断缺失；演示事件在新旧快照页面都有可理解的名称；规则提示与未核实异常之间的边界清楚；迁移仅影响精确匹配的演示对象。
